About SeederKit

Development data tooling for Rails applications

This page is the zero-setup version of SeederKit: paste a Rails schema and get a starter db/seeds.rb file. The larger project is a Rails engine for deterministic, schema-aware data generation and scenario orchestration.

The next direction is deeper domain modeling: richer relationship handling, reusable scenario definitions, and seed output that can grow from quick prototypes into repeatable development workflows.
