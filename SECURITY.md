# Security Policy

## Supported Versions

SeederKit is pre-release software. Security fixes are applied to the current
`main` branch until a public release support policy is published.

## Reporting A Vulnerability

Do not report suspected vulnerabilities in a public issue.

Use the repository's
[private vulnerability reporting](https://github.com/CoryMCodes/seeder_kit/security/advisories/new)
to share the affected version or commit, reproduction steps, impact, and any
known mitigation.

Maintainers will acknowledge a report within seven days and provide an initial
assessment or request additional information. Disclosure timing will be
coordinated after a fix or mitigation is available.
