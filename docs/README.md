# SeederKit Docs

SeederKit's product center is the Rails engine workflow for named, validated,
composable development states. The standalone `schema.rb -> seeds.rb` web
generator is a separate public utility.

Start here:

- [Root README](../README.md) for shipped behavior, examples, and current limitations.
- [Architecture Plan](architecture-plan.md)
- [Usable-State Product Roadmap](../_bmad-output/planning-artifacts/seederkit-usable-state-roadmap-2026-06-08.md)

The roadmap sequences the work required for the first externally usable product.
The architecture plan records current service boundaries and implementation
checkpoints. The older `notes/` directory contains reasoning snapshots and is
not the current product contract.
